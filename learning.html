BEGINNER ROUTE

Start with a classic ESP32 DevKit. Follow each guide’s exact board, wiring and software assumptions. These are learning steps, not promised completion times.

  1. 01

    Arduino IDE setup

    Install the board package, select your board and port, then verify a Serial-only upload.

    Parts & before you start

    ESP32 DevKit, data-capable USB cable and computer.

    Start here; no circuit or onboard LED is required.

  2. 02

    Blink LED

    Wire an external LED and control a digital output.

    Parts & before you start

    Add an LED, 220 ohm resistor, breadboard and jumper wires.

    First confirm the Serial upload in step 1 works.

  3. 03

    Button input

    Read a button with INPUT_PULLUP and use it to control the LED.

    Parts & before you start

    Add a pushbutton; reuse the LED circuit and breadboard.

    First make the external LED blink in step 2.

  4. 04

    DHT11 sensor

    Install a sensor library and read temperature and humidity in Serial Monitor.

    Parts & before you start

    Add a DHT11; check the guide for bare-sensor versus module wiring and pull-up requirements.

    Keep the working upload setup and practise the button wiring before adding a sensor.

  5. 05

    OLED display

    Wire an SSD1306 I2C OLED and show text. Combining sensor values is a later exercise.

    Parts & before you start

    Add the guide’s 128×64 SSD1306 I2C OLED; verify its supply and signal requirements.

    Use the library-installation and Serial Monitor skills from step 4.

BEFORE YOU START

A few good questions.

Can I learn ESP32 without programming experience?

Begin with the board introduction and Arduino IDE setup. Follow a complete example, change one thing and check the result. Standalone programming topics marked planned do not have dedicated lessons yet.

Does this roadmap contain 100 complete tutorials?

No. It is a 100-topic curriculum map. “Guide linked” means an existing study guide or section covers the topic. Several topics can share a guide. Planned topics are future curriculum ideas and have no lesson link.

Will my progress sync to my phone?

No. Progress starts in this tab. If you enable saving, it is kept in this browser on this device. Private browsing, clearing site data or changing device can remove it. There is no account or server sync.

Can I skip straight to IoT or robotics?

You can open any path. First verify that you can upload, read a simple input and control a safe output. For motors or powered loads, follow the exact driver and supply requirements; never power a motor from GPIO.
