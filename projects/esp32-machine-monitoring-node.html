ESP32 Threshold-to-Relay Bench Lesson

Practice ADC hysteresis and a timed manual enable with a potentiometer, specified STEMMA relay and separate low-voltage LED load. No machine monitoring or current measurement.

BuildWhat You Will Build

A potentiometer simulates a changing signal. The ESP32 screens its divided ADC input and applies two thresholds to an explicitly supported relay controlling only a separate battery/LED circuit. The historical machine-monitoring URL is retained; no current sensor, real machine, cloud sync, protective trip or maintenance diagnosis is implemented.

SetupBefore You Start

Classic ESP32-WROOM-32/32E DevKit, Arduino IDE 2.x and Arduino-ESP32 3.3.2 review baseline; built-in ADC/GPIO only, no external library. Free GPIO35 (ADC1 input only, no internal pulls) and GPIO19. Not a pin map for S3/C3/C5. Identify the actual board 3V3 rail and verify 3.0–3.45 V before relying on the bounds below.

👨‍👩‍👧

For Parents & Teachers

Only the documented 3 V battery/LED contact circuit is supported. No mains, motors, real machines or unattended operation. Remove all three power sources before rewiring. Software commands/timeouts and normally-open contacts are not independent safety protection; welded contacts or hardware failure can leave a load on.

Parts

  • 📦Classic ESP32-WROOM-32/32E DevKitUSB power; exposed GPIO35 and GPIO19; 3.3 V logic.
  • 📦10 kΩ linear potentiometerOuter terminals to board 3V3/GND; identify wiper with continuity/resistance while unpowered.
  • 📦15 kΩ and 10 kΩ divider resistors, both 1%; 100 nF capacitorOne divider at GPIO35; additional 10 kΩ Signal pull-down at relay.
  • 📦Adafruit STEMMA Non-Latching Mini Relay 4409 and JST-PH 3-pin cableActive HIGH. Other relay boards, including latching/active-LOW modules, are not substitutes.
  • 📦External regulated 5 V relay supply rated at least 100 mAManufacturer coil draw about 50 mA; GPIO supplies signal only. Common ground, separate positive rails.
  • 📦Separate 3 V battery, red LED and 330 ohm resistorOnly supported contact-side load; no motor, machine, heater or mains.
  • 📦Breadboard, jumper leads and USB data cableKeep contact-side battery circuit separate from control ground.

🔗Wiring

USB powers the ESP32. Board 3V3 supplies only the potentiometer; its divided wiper reaches GPIO35. A separate 5 V supply powers the identified relay with common control ground. GPIO19 commands Signal with a pull-down. Relay COM/NO switches a separate 3 V battery/LED circuit.

Open wiring diagram full size

  1. 1

    Disconnect USB, relay supply and LED battery before wiring. Verify actual connector and contact labels; the diagram is logical, not physical pin order.

  2. 2

    Pot outer terminals → board 3V3/GND. Wiper → 15k → GPIO35 node; 10k and 100 nF separately node → GND. Never use VIN/5V for the pot.

  3. 3

    STEMMA red Vin → separate regulated +5 V; black GND → supply negative and ESP32 GND. Never join external +5 V with USB/DevKit positive rails.

  4. 4

    STEMMA white Signal → GPIO19; additional 10k Signal → common GND. Confirm model 4409, not a generic relay input.

  5. 5

    Separate 3 V battery positive → COM; NO → 330 ohm → red LED anode; LED cathode → battery negative. NC unused. Do not join this battery return to controller ground.

  6. 6

    Check circuit while unpowered, then power controller/relay together. Upload; open Serial Monitor at 115200. Command starts OFF. Turn pot slowly; send E to enable for 10 seconds or X to disable.

SettingsConfigure the Example

Use Serial Monitor at 115200; E enables or renews a 10-second window, X disables; newline characters are ignored. Start with the LED circuit connected, not a real load. Valid input is screened to 250–1500 mV with no rail samples and at most 30 mV span in a 16-sample window. These are lesson choices, not certified sensor-fault detection. The lowest pot position deliberately rejects and disables. Re-enable with E after a rejected window or timeout.

⌨️Code

Install the libraries above and match the configuration and wiring before uploading.

esp32-machine-monitoring-node.ino 
#include <Arduino.h>
// Classic ESP32-WROOM DevKit; Arduino-ESP32 3.3.2 review baseline.
// 10k linear potentiometer outer terminals: board 3V3 and GND.
// Wiper -- 15k (1%) -- GPIO35 node; 10k (1%) and 100 nF node to GND.
// GPIO19 -> STEMMA 4409 Signal; 10k Signal to common GND.
constexpr uint8_t INPUT_PIN = 35, RELAY_PIN = 19;
constexpr uint32_t ENABLE_MS = 10000;
constexpr float ON_MV = 900, OFF_MV = 650;
bool enabled = false, relayOn = false;
uint32_t enabledAt = 0;
void off() { relayOn = false; digitalWrite(RELAY_PIN, LOW); }
void setup() {
  digitalWrite(RELAY_PIN, LOW);
  pinMode(RELAY_PIN, OUTPUT);
  off();
  Serial.begin(115200);
  analogReadResolution(12);
  analogSetPinAttenuation(INPUT_PIN, ADC_11db);
  Serial.println("Potentiometer/LED bench lesson only; no machine or current measurement");
  Serial.println("E enables for 10 seconds; X disables. Use Serial Monitor at 115200.");
}
void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == 'x' || c == 'X') { enabled = false; off(); }
    if (c == 'e' || c == 'E') { enabled = true; enabledAt = millis(); }
  }
  uint32_t sum = 0, rawSum = 0, lo = 100000, hi = 0;
  bool rail = false;
  for (int i = 0; i < 16; ++i) {
    uint16_t raw = analogRead(INPUT_PIN);
    uint32_t mv = analogReadMilliVolts(INPUT_PIN);
    rawSum += raw; sum += mv;
    if (raw <= 16 || raw >= 4079) rail = true;
    if (mv < lo) lo = mv;
    if (mv > hi) hi = mv;
    delay(2);
  }
  float pinMv = sum / 16.0f;
  bool valid = !rail && lo >= 250 && hi <= 1500 && hi - lo <= 30;
  if (!valid || (enabled && uint32_t(millis() - enabledAt) >= ENABLE_MS)) {
    enabled = false; off();
  }
  if (!enabled) off();
  else {
    if (!relayOn && pinMv >= ON_MV) relayOn = true;
    else if (relayOn && pinMv <= OFF_MV) relayOn = false;
    digitalWrite(RELAY_PIN, relayOn ? HIGH : LOW);
  }
  Serial.printf("raw_counts=%.1f ADC_pin_mV_est=%.1f input=%s enabled=%s command=%s\n",
    rawSum / 16.0f, pinMv, valid ? "screened" : "INVALID",
    enabled ? "yes" : "no", relayOn ? "ON" : "OFF");
  delay(100); // Acquisition + reporting delay: not an exact sampling period.
}

CodeHow the Code Works

Raw counts and calibrated ADC-pin mV estimates come from separate conversions, not a simultaneous measurement. Startup is disabled/OFF. While enabled, input >=900 mV commands HIGH/ON; <=650 mV commands LOW/OFF; between those boundaries retains the prior state. X, invalid screening or elapsed 10 seconds commands OFF and clears enable. E can allow ON at the next valid sample when input is already high; there is no mechanical interlock. The finite sampling loop and report delay mean commands/timeouts are not instantaneous.

✨Expected Output

Prospective behavior, not observed hardware results: Serial reports raw counts, estimated ADC-pin mV, input screen, enable and command. Without E, command remains OFF. With E and a valid input >=900 mV it becomes ON; <=650 mV becomes OFF; the interval keeps state. Invalid input, X or timeout commands OFF. Actual contact/LED operation has not been tested; do not equate a printed ON with verified contacts.

🔧Troubleshooting

  • Command stays OFF Read input/enable states. E is required; reject states or a low pot position disable the window. Do not bypass screening.
  • Command and LED disagree Remove all power; identify 4409 and COM/NO labels, LED polarity, battery and resistor. A printed command is not contact feedback.
  • Repeated invalid/noisy input Power off; verify pot wiper, ground, divider and capacitor. Record diagnostics; do not treat a software range test as proof of electrical safety.

Checks to Perform on Your Build

  • Documentation/API and numerical review only; no compilation or hardware results supplied.
  • Use only the specified LED circuit; record actual signal, commanded state and observed LED separately.
  • Check disabled startup, upper/lower thresholds, deadband, X, low-input rejection and timeout.

DetailsPractical Design Notes

Vpin = Vwiper × Rbottom/(Rtop+Rbottom). Nominal 15k/10k ratio is 0.4; the 1% maximum ratio is 10.1/(14.85+10.1)=0.40481. With a verified board rail no higher than 3.45 V, maximum pin voltage is approximately 1.3966 V. Pot resistance/loading changes the wiper response, so angle is not a calibrated voltage scale. Classic ESP32 11 dB usable measurement range is about 150–3100 mV, separate from 3.3 V logic and supply ratings. The lesson rejects below 250 mV instead of estimating accurately near zero. A divider calculation is not transient protection, ADC accuracy or physical electrical validation. A disconnected wiper is pulled down, but an in-range stuck signal can pass. Hysteresis thresholds are arbitrary demonstration values, not current, machine-health or protective-trip settings.

⬆️Upgrade Ideas

  • A real current-sensor interface requires a separately documented transfer function, voltage limits, wiring and calibration.
  • Cloud, OLED and protective functions are not implemented here.

FAQs

Does this measure current or protect a machine?

No. The potentiometer is a signal simulator and the load is a battery LED. No current measurement, machinery wiring or independent protective function is implemented.

Does LOW prove the contact is open?

No. It is a software command; contact state needs independent observation and faults are not excluded.
