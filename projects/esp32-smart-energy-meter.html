BuildWhat You Will Build

Read two defined resistor-divider inputs on classic ESP32 ADC1. Log raw counts in Serial Monitor; no voltage/current sensor, power or energy measurement is implemented. The historical energy-meter URL is retained, but this is an acquisition prerequisite, not a metering implementation.

SetupBefore You Start

Classic ESP32-WROOM-32/32E DevKit with free GPIO36 and GPIO34, Arduino IDE 2.x, Arduino-ESP32 3.3.2 review baseline. Built-in ADC functions only; not a latest-release claim. A meter/continuity check and basic resistor identification are prerequisites.

👨‍👩‍👧

For Parents & Teachers

Low-voltage educational arrangement, not verified hardware or a safety certification. USB board power only; never connect mains, an appliance, battery pack, motor or unknown sensor output. Unplug before rewiring.

Parts

  • 📦Classic ESP32-WROOM-32/32E DevKit with exposed GPIO36 and GPIO34USB-powered board; identify GPIO numbers rather than connector positions. Not an S3/C3/C5 pin map.
  • 📦Three 10 kΩ and one 20 kΩ resistors, all 1%Channel A top/bottom 10k/10k; channel B top/bottom 20k/10k.
  • 📦Two 100 nF ceramic capacitors, breadboard and short jumper leadsOne capacitor from each ADC node to GND. Check breadboard rail breaks.
  • 📦USB data cable and computer with Arduino IDE 2.xNo external supply, voltage/current module, OLED or relay is connected.

🔗Wiring

Two passive dividers use only the USB-powered board 3V3 rail: 10k/10k feeds GPIO36; 20k/10k feeds GPIO34. Each node has 100 nF to common GND. No external signal source, sensor, load, relay or display is part of the circuit.

Open wiring diagram full size

  1. 1

    Disconnect USB before wiring; do not connect external sources or loads. Identify board 3V3, GND, GPIO36 and GPIO34 from its pin labels.

  2. 2

    A: board 3V3 → 10 kΩ → node A → 10 kΩ → GND; node A → GPIO36.

  3. 3

    B: board 3V3 → 20 kΩ → node B → 10 kΩ → GND; node B → GPIO34.

  4. 4

    Connect one 100 nF capacitor separately from each ADC node to GND. Use common board ground; keep the two nodes distinct.

  5. 5

    Check resistance/continuity while unpowered. Verify the board 3V3 rail is within 3.0–3.45 V before relying on the stated voltage bounds; never use VIN/5V as the divider rail.

  6. 6

    Reconnect USB, upload for the matching classic ESP32 board, then open Serial Monitor at 115200. Do not alter powered wiring.

SettingsConfigure the Example

Select the matching classic ESP32 board and port. Set Serial Monitor to 115200. No credentials, calibration coefficients or sensor defaults are required. Keep Wi-Fi disabled in this example; ADC1 selection does not make it an energy meter.

⌨️Code

Install the libraries above and match the configuration and wiring before uploading.

esp32-smart-energy-meter.ino 
#include <Arduino.h>
// Classic ESP32-WROOM-32/32E DevKit; Arduino-ESP32 3.3.2 review baseline.
// A: 3V3 -- 10k -- GPIO36 node -- 10k -- GND.
// B: 3V3 -- 20k -- GPIO34 node -- 10k -- GND.
// All resistors 1%; each ADC node also has 100 nF to GND.
constexpr uint8_t CHANNEL_A = 36, CHANNEL_B = 34;
struct Reading { float counts; bool nearRail; };
Reading readCounts(uint8_t pin) {
  uint32_t sum = 0;
  bool rail = false;
  for (int i = 0; i < 32; ++i) {
    uint16_t raw = analogRead(pin);
    sum += raw;
    if (raw <= 16 || raw >= 4079) rail = true;
    delay(2);
  }
  return {sum / 32.0f, rail};
}
void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
  analogSetPinAttenuation(CHANNEL_A, ADC_11db);
  analogSetPinAttenuation(CHANNEL_B, ADC_11db);
  Serial.println("Two sequential raw ADC channels; NOT an energy meter");
}
void loop() {
  Reading a = readCounts(CHANNEL_A);
  Reading b = readCounts(CHANNEL_B);
  Serial.printf("A_GPIO36_raw_counts=%.1f B_GPIO34_raw_counts=%.1f\n",
                a.counts, b.counts);
  if (a.nearRail || b.nearRail)
    Serial.println("CHECK_WIRING: near-rail sample; no derived result");
  delay(500); // Pause after acquisition; not an exact 500 ms sampling period.
}

CodeHow the Code Works

Each channel averages 32 raw samples, then prints counts. A and B are acquired at different times. A near-rail sample produces CHECK_WIRING, but a plausible count cannot prove correct wiring or connection. The delay is a reporting pause after acquisition, not a precise sample period.

✨Expected Output

Serial prints two labelled raw-count averages and may print CHECK_WIRING. With the stated network A should generally read higher than B; no recorded counts, voltage measurement, watts or watt-hours are supplied. If not, stop and inspect the unpowered circuit. This is expected behavior, not hardware test evidence.

🔧Troubleshooting

  • Zero or near-rail readings Disconnect USB. Check divider orientation, common GND, GPIO labels and rail continuity. Never fix saturation by forcing a plausible software value.
  • A is not generally higher than B Check the 20k top resistor belongs to channel B, both 10k bottom resistors reach GND and nodes are not joined. Actual counts are not calibration data.
  • Plausible but unchanged reading Fixed dividers intentionally give near-steady inputs. A disconnected/floating pin can also look plausible; use unpowered continuity checks and appropriate instruments, not a count alone.

Checks to Perform on Your Build

  • Documentation/API and divider arithmetic reviewed only; compilation and hardware operation unperformed.
  • Verify actual rail, resistor values and connections independently before interpreting readings.
  • Compare Copy text with the full sketch; record actual observations separately from this expected-output description.

DetailsPractical Design Notes

Vnode=Vrail×Rbottom/(Rtop+Rbottom). Nominal 3.3 V gives 1.65 V at A and 1.10 V at B: calculated circuit values, not observed readings. For a verified 3.0–3.45 V rail and 1% resistors, A is bounded about 1.485–1.7423 V; B about 0.9867–1.1654 V, ignoring loading. These are inside the documented classic ESP32 11 dB measurement range of approximately 150–3100 mV. Supply voltage, 3.3 V GPIO logic and usable ADC range are different concepts; 5 V is not an acceptable GPIO signal. GPIO34/36 are ADC1 input-only with no internal pull resistors. This sketch reports uncalibrated 12-bit counts (0–4095), not pin voltage. Do not use counts×3.3/4095 as a calibrated voltage conversion. ADC nonlinearity, rail tolerance, loading and wiring affect observations. No exact count ratio or accuracy is promised. Averages are sequential, not simultaneous waveforms; multiplying these counts does not measure power. Real power requires a defined voltage/current transfer function, offset handling and time-aligned acquisition appropriate to the waveform. Energy additionally requires integration over elapsed time. None is implemented here.

⬆️Upgrade Ideas

  • Deferred: OLED output requires a separate complete display initialization/rendering sketch; no OLED is wired or driven here.
  • A future metering project needs exact documented transducers, signal conditioning, sampling design and independent reference checks; arbitrary modules are not drop-in additions.

FAQs

Does this measure energy?

No. The historical URL is unchanged; the implementation only logs two raw ADC channels.

Can I connect a voltage/current module?

Not using these instructions. Its exact output range, reference, transfer function and protection must first be defined separately.

Where is the OLED output?

It is deferred, not implemented. This sketch uses Serial Monitor only.
