🧒Explain Like I'm 12

The clamp surrounds one insulated wire in a low-voltage AC loop. It produces an AC signal on a separate winding. The bias circuit shifts that signal around mid-rail for the ESP32 ADC.

For Parents & Teachers

This exercise is limited to an isolated low-voltage AC arrangement with a current limit or fuse appropriate to the load and conductors. Never open mains wiring or connect mains to this circuit. A clamp does not make mains work beginner-safe. Power off both bench source and USB before rewiring. Not a certified or billing-grade meter.

🔗Wiring

Only the isolated 12 V AC source and its low-voltage load form the sensed loop. The SCT-013-030 has a built-in burden; its secondary output feeds the separate biased GPIO34 circuit.

Open wiring diagram full size

  1. 1

    Unplug USB before changing the ADC bias circuit.

  2. 2

    Build the 10 kOhm / 10 kOhm divider between 3.3 V and GND.

  3. 3

    Connect the divider midpoint to GPIO34.

  4. 4

    Couple the SCT-013 tip signal into the midpoint through the 10 uF capacitor, observing capacitor polarity for the biased node.

  5. 5

    Connect the SCT-013 sleeve to ESP32 GND on the low-voltage side.

  6. 6

    With the isolated 12 V AC source OFF, clamp around ONE insulated conductor between that source and its matching low-voltage load. Do not clamp the complete two-wire cable; no mains lead is used.

  7. 7

    Before GPIO34 is connected, verify the midpoint and waveform with a meter/oscilloscope: keep the complete waveform within approximately 0.2–2.9 V for headroom inside the classic ESP32 11 dB measurement range. Limit the low-voltage source/load accordingly. The bias divider is not an overvoltage clamp.

Circuit Explanation

The SCT-013 produces an isolated AC signal proportional to current. The bias network shifts that waveform into the ESP32 ADC range so EmonLib can estimate RMS current.

Engineering Explanation

The SCT-013-030 is the 30 A / 1 V voltage-output version with an internal burden; it is not interchangeable with an SCT-013-000 current-output clamp. A small low-voltage bench load may produce readings dominated by ADC noise. The two 10 kΩ resistors bias the input nominally to 1.65 V; the 10 µF coupling capacitor has its positive terminal toward the biased ADC node. Verify actual waveform bounds, not just midpoint. EmonLib 1.1.0 assumes 10-bit counts on non-ARM builds; this example explicitly requests that resolution. Neither that change nor the library establishes calibration. The assumed 12 V multiplication is only an illustrative VA estimate, not measured voltage, watts, power factor or energy.

Libraries

  • Arduino-ESP32 3.3.2Classic ESP32-WROOM review baseline. Uses 10-bit analogRead here to match EmonLib non-ARM ADC_COUNTS, not the default 12-bit setting.
  • EmonLib 1.1.0OpenEnergyMonitor library. ICAL=29 is an unvalidated starter factor; ADC transfer, CT tolerance and coupling network require a separate calibration. No ESP32 firmware compilation or current-accuracy result is claimed.

⌨️Code

Copy into Arduino IDE. Install any libraries noted in the component guides first.

esp32-ac-power-monitor.ino 
// ESP32 Isolated AC Current Monitor Prototype
// Isolated current-limited 12 V AC bench loop ONLY; no mains wiring.
// Arduino-ESP32 3.3.2 / EmonLib 1.1.0 review baseline; uncalibrated estimate.
#include "EmonLib.h"

EnergyMonitor emon;
const int CT_PIN = 34;          // ADC1 input at 1.65 V biased midpoint
const float ICAL = 29.0;        // Starter calibration; tune with a known safe reference
const float ASSUMED_VOLTAGE = 12.0; // Nominal bench AC source, not measured voltage

void setup() {
  Serial.begin(115200);
  analogReadResolution(10);
  analogSetPinAttenuation(CT_PIN, ADC_11db);
  emon.current(CT_PIN, ICAL);
  Serial.println("Educational isolated CT current monitor. Not billing-grade.");
}

void loop() {
  double irms = emon.calcIrms(1480);
  double apparentPower = irms * ASSUMED_VOLTAGE;
  Serial.printf("Irms estimate: %.3f A  Apparent power estimate: %.1f VA\n", irms, apparentPower);
  delay(5000);
}

Code Explanation

CT_PIN is GPIO34. EmonLib samples the biased waveform, estimates RMS current, and multiplies by an assumed voltage only for apparent-power practice.

✨Expected Output

Serial Monitor prints Irms estimate and apparent power estimate every five seconds. Treat both as prototype estimates that need calibration.

🔧Troubleshooting

  • Current reads near zero Confirm the clamp surrounds one conductor only and the jack wiring reaches GPIO34.
  • Readings drift Check the midpoint bias and capacitor orientation.
  • Values disagree with a meter Tune ICAL against a known safe reference; do not claim precision.

MistakesCommon Mistakes

  • Using a DC source: a current transformer requires changing current.
  • Clamping around both low-voltage source and return conductors, cancelling the field.
  • Assuming a mid-rail divider prevents excessive waveform peaks.
  • Treating a nominal-voltage VA calculation as measured watts or billing energy.

Testing Checklist

  • Confirm the source is factory-isolated 12 V AC with an appropriate current limit/fuse and matching low-voltage load.
  • Verify bias and waveform limits before connecting GPIO34.
  • Record unloaded noise and a supervised low-voltage load observation separately from any reference measurement.
  • Do not infer useful low-current precision from plausible Serial output.

TipsEngineering Tips

  • Use only the isolated low-voltage AC arrangement described here.
  • Check the CT model and secondary plug contacts before wiring.
  • Keep all accuracy claims pending an actual reference comparison.

⬆️Upgrade Ideas

  • Display the explicitly uncalibrated estimate on an OLED.
  • Log the bench source, load and ADC settings with each observation.

FAQs

Is mains wiring covered?

No. Only the isolated, current-limited low-voltage AC loop is supported; a clamp does not make mains work safe for beginners.

Why can a small load read almost zero?

The selected CT is rated 30 A / 1 V. A small bench current produces a small secondary voltage and may be obscured by ADC noise.

Are the displayed amps or VA calibrated?

No. ICAL is an unvalidated starter value and 12 V is assumed, not measured. No accuracy result is supplied.
