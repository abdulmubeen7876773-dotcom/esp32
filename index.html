Start here: five beginner steps

Follow this order with a classic ESP32 WROOM DevKit and Arduino-ESP32 3.x. Each guide explains its exact hardware assumptions. Finish each expected result before moving on.

  1. Step 1 · Beginner · 10 min read

    Arduino IDE setup

    Install the board package, select your board and port, then verify a Serial-only upload.

    Parts: ESP32 DevKit, data-capable USB cable and computer.

    Before you start: Start here; no circuit or onboard LED is required.

  2. Step 2 · Beginner · Reading estimate: 10–15 min

    Blink LED

    Wire an external LED and control a digital output.

    Parts: Add an LED, 220 ohm resistor, breadboard and jumper wires.

    Before you start: First confirm the Serial upload in step 1 works.

  3. Step 3 · Beginner · Reading estimate: 15-20 min

    Button input

    Read a button with INPUT_PULLUP and use it to control the LED.

    Parts: Add a pushbutton; reuse the LED circuit and breadboard.

    Before you start: First make the external LED blink in step 2.

  4. Step 4 · Beginner · Reading estimate: 14-18 min

    DHT11 sensor

    Install a sensor library and read temperature and humidity in Serial Monitor.

    Parts: Add a DHT11; check the guide for bare-sensor versus module wiring and pull-up requirements.

    Before you start: Keep the working upload setup and practise the button wiring before adding a sensor.

  5. Step 5 · Beginner · Reading estimate: 10–15 min

    OLED display

    Wire an SSD1306 I2C OLED and show text. Combining sensor values is a later exercise.

    Parts: Add the guide’s 128×64 SSD1306 I2C OLED; verify its supply and signal requirements.

    Before you start: Use the library-installation and Serial Monitor skills from step 4.

Need background first? Read What is ESP32? and the DevKit board guide. After these five steps, choose a sensor path or display path.
