Active Buzzer Module: Safe ESP32 On/Off Control

Switch a documented active buzzer through an NPN transistor. Keep buzzer power off the GPIO and distinguish a powered signal terminal from a low-current logic input.

Before you start

Board and software
Classic ESP32-WROOM-32/32E DevKit with the listed GPIOs exposed and unused. Arduino IDE 2.x; esp32 by Espressif Systems 3.3.2 (review baseline, not a latest-release claim). Select the documented board or ESP32 Dev Module for a generic WROOM board. Other families need their own pin map. Serial Monitor: 115200 baud.
Supported hardware
Worked reference: Joy-IT COM-KY012APB / KY-012 as documented in its May 2024 manual: voltage between S (powered terminal) and GND makes sound; middle pin is not connected. The generic approved module illustration is not identified as this product. Do not transplant this wiring to a VCC/GND/IN board without its schematic.
Prerequisites and parts
Complete Blink and the NPN switching lesson. Documented Joy-IT module, onsemi P2N2222A, 680 ohm base resistor, 100 kOhm base-emitter pull-down, short wires and a regulated 5 V supply rated for the documented module current. ESP32 remains USB powered; join grounds, not positive rails.
Libraries
No extra library. Arduino-ESP32 3.3.2 GPIO and millis APIs.
Expected result
A fixed-pitch beep for 200 ms followed by 1800 ms silence. The sketch controls the envelope, not pitch.
Verification status
Documentation and source review only. Not compiled or tested on hardware. The approved product-style illustration identifies a family, not a verified physical pin layout or manufacturer-authenticated board. Follow the logical diagram and documentation for your actual part.

Overview

An active buzzer contains an oscillator, so steady power produces a tone. Turn that power on and off to make alert patterns. A passive buzzer instead needs an alternating drive signal and can play different pitches. The approved image depicts an active-module family but cannot verify a real unit’s oscillator or trigger polarity.

The reference KY-012 terminal S carries buzzer power, not just a logic command. Use the transistor below instead of drawing buzzer current from ESP32 GPIO. Other active modules may have separate VCC and IN, active-LOW control or different ratings.

Wiring and matching Arduino code

Short beep envelope

External +5 V → KY-012 S; KY-012 minus → NPN collector; emitter → common GND. GPIO25 → 680 ohm → base, 100 kOhm base-emitter; middle NC.

active_buzzer_module.ino 
#include <Arduino.h>
constexpr uint8_t OUTPUT_PIN = 25;
bool active = false;
uint32_t changedAt = 0;
void setup() {
  Serial.begin(115200);
  pinMode(OUTPUT_PIN, OUTPUT);
  digitalWrite(OUTPUT_PIN, LOW);
  Serial.println("Starts OFF; repeating on/off demonstration");
}
void loop() {
  const uint32_t now = millis();
  const uint32_t interval = active ? 200 : 1800;
  if (now - changedAt >= interval) {
    changedAt = now;
    active = !active;
    digitalWrite(OUTPUT_PIN, active ? HIGH : LOW);
    Serial.println(active ? "ON" : "OFF");
  }
}

HIGH switches the transistor on in this circuit. No tone() or PWM is needed for the active reference. The software OFF state and hardware pull-down assume correct wiring; this is not a fail-safe alarm.

OKExpected Output

A short repeating beep is expected from the supported reference. A click without a steady tone during the ON interval can indicate a passive device, wrong voltage or poor wiring; do not compensate by blindly changing pin polarity.

How it works

GPIO current enters the base through 680 ohm. The collector switches the buzzer return while its S terminal remains at 5 V. The roughly 3.7 mA base-drive estimate provides margin for the documented 30 mA load using an approximately 10:1 forced-gain design target. Actual junction drop and current vary; no values were measured.

06Troubleshooting

ProblemPossible causeSolution
Only clicks Passive buzzer or unsuitable supply. Match the exact active reference and check voltage across its S/minus terminals during ON.
Continuous sound Buzzer return bypasses transistor or transistor is shorted. Unplug power; trace the switched return and verify the base pull-down.
A different module behaves backwards Different trigger circuit or pin order. Stop and obtain its schematic; neither polarity nor GPIO compatibility follows from the module name.

Where you use it

  • Non-safety-critical reminders
  • Button confirmation beeps
  • Status alerts with a fixed tone
