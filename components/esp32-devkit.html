Before you start

Board
Classic ESP32-WROOM-32/32E DevKit with USB-to-UART bridge, GPIO16 exposed and unused. DevKitC V4 documentation is the reference; clone vendor, bridge and exact header layout are unspecified.
Software
Arduino IDE 2.x; esp32 by Espressif Systems 3.x (API review baseline 3.3.2). Serial Monitor: 115200 baud. Choose the documented board profile; ESP32 Dev Module is the generic classic WROOM fallback.
Parts
Known USB data cable, breadboard, LED, 220 Ω series resistor and jumper wires for the optional external LED test.
Prerequisite
Identify the module, USB bridge and printed GND/GPIO16 labels before wiring. First verify upload with the Serial-only sketch in the installation guide.
Expected result
External LED alternates ON/OFF every half second with matching serial text. Documentation/API reviewed; not compiled or hardware tested.

Which ESP32 DevKit this page covers

A DevKit adds USB programming, a voltage regulator, buttons and headers around an ESP32 module. The example here uses a classic ESP32-WROOM board, not ESP32-C3, S2, S3 or a WROVER/PSRAM board. These families share branding but differ in GPIO maps, USB options and peripherals.

Read the metal module marking and the exact board documentation first. A 30-pin clone and a 38-pin DevKitC do not have the same physical header positions. GPIO16 in code means chip GPIO16, not the sixteenth header pin. IO16 may mean GPIO16; an unexplained D label needs the board pin map.

Wiring and matching Arduino code

Optional external LED test on WROOM GPIO16

USB power; GPIO16 → 220 Ω → LED anode, LED cathode → GND. Use the exact WROOM pin map.

esp32_devkit_blink_test.ino 
#define LED_PIN 16

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("ESP32 DevKit external LED blink test started");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  Serial.println("LED ON");
  delay(500);

  digitalWrite(LED_PIN, LOW);
  Serial.println("LED OFF");
  delay(500);
}

This example is for classic WROOM GPIO16. A WROVER/PSRAM board may reserve GPIO16/17. Never replace LED_PIN with an arbitrary header position or input-only pin.

OKExpected Output

Expected, not measured: Serial Monitor at 115200 baud alternates LED ON and LED OFF about every half second. The external LED should follow. If text works but the LED does not, check its polarity, resistor placement and actual GPIO label; a power LED staying lit is normal.

Classic ESP32 GPIO and ADC limits

For classic ESP32, GPIO34–39 are input-only and have no internal pull-up/down. Not every module exposes every pin in that range; many WROOM boards expose only 34, 35, 36 and 39. Use an external bias resistor for an otherwise floating switch input.

GPIO0, 2, 5, 12 and 15 are strapping pins sampled during reset. Avoid them for first circuits because attached pull resistors and loads can change startup behavior. GPIO6–11 are used for flash; board labels D0/D1/D2/D3/CMD/CLK in the DevKitC map refer to these flash signals. GPIO1/3 normally carry UART upload and serial output.

GPIO16/17 are available on the documented WROOM board but reserved for internal use on WROVER modules. Do not carry these restrictions over unchanged to C3/S2/S3 boards; consult their own documentation.

On classic ESP32, ADC2 conflicts with active Wi-Fi. Choose an exposed ADC1 pin such as GPIO32 or GPIO33 for a beginner Wi-Fi analog project. GPIO34/35/36/39 can also be ADC1 inputs where exposed, but need externally defined signals. ADC readings require appropriate attenuation and calibration; 3.3 V GPIO logic does not guarantee an accurate ADC range up to 3.3 V.

06Troubleshooting

ProblemPossible causeSolution
No new Windows COM port Cable, hub/connector or bridge driver problem. Use a known data cable and direct USB port. In Device Manager unplug/replug to identify the device. Read the bridge marking or hardware ID: use Silicon Labs for CP210x, WCH for the matching CH340/CH341/other WCH chip, or the actual vendor. BOOT does not install a driver.
Failed to connect / stuck on Connecting Wrong port, external wiring on boot/UART pins or missing automatic reset. Close other serial apps and disconnect peripherals. For a classic BOOT/EN UART board only: hold BOOT, tap EN, start upload and release BOOT when writing begins. After flashing, tap EN if it stays in download mode. Consult board instructions for native USB variants.
LED does not blink Wrong header, reversed LED or pin reserved by variant. Verify WROOM GPIO16 and the series resistor. On WROVER select a documented free output and change wiring/code together. GPIO34–39 cannot drive the LED.
Board stops booting after wiring Strapping/flash/UART pin conflict. Disconnect the new circuit and retest. Avoid classic GPIO0/2/5/12/15 and flash GPIO6–11 for beginner additions.
Analog reads fail when Wi-Fi runs Classic ADC2/Wi-Fi resource conflict. Move the analog signal to available ADC1, for example GPIO32/33, and update code. Check input voltage, attenuation and calibration.
Unreadable serial / resets Wrong baud or unstable supply. Use 115200 baud for this sketch and a sound cable. Remove heavy loads. If the board becomes hot, disconnect power and inspect for shorts.
