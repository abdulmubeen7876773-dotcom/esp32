Before you start

Board
Classic ESP32-WROOM-32 DevKit with GPIO4 available. Select ESP32 Dev Module for an otherwise undocumented generic WROOM board; use an exact supported profile when known.
Sensor
Bare four-pin DHT22/AM2302 package or a verified 3.3 V-compatible breakout. Vendor and module pin order are unspecified; follow its labels and documentation.
Software
Arduino IDE 2.x; esp32 by Espressif Systems 3.x (API review baseline 3.3.2). Serial Monitor: 115200 baud. Install DHT sensor library by Adafruit (API reference 1.4.6) and its Adafruit Unified Sensor dependency using Library Manager.
Parts
USB data cable, short jumper wires, breadboard and 10 kΩ DATA-to-3.3 V pull-up for a bare sensor. Check whether a breakout already includes that resistor.
Expected result
One temperature/humidity line about every 2.5 seconds, or a clear failed-read message. Documentation/API reviewed; not compiled or hardware tested.

What DHT22 measures and when to choose it

DHT22 measures air temperature in °C and relative humidity in % RH. It does not measure pressure. Choose it for slow indoor comfort logging or a classroom sensor build. For pressure too, consider BME280. Neither sensor is a weatherproof enclosure or a calibrated laboratory instrument.

DHT22 normally offers a wider temperature/humidity range and finer readings than the older DHT11 models described by Adafruit. DHT11 is useful when you already own one and only need a basic room demonstration. Match the library sensor type to the actual part; similar wiring does not make the two interchangeable in code.

03Pinout

  • 1: VCC Bare sensor power 3.3 V For the standard bare package, face the vented front toward you with leads pointing down; count left to right. Verify the part datasheet before power.
  • 2: DATA Bidirectional digital signal GPIO4 and 10 kΩ to 3.3 V Do not use an input-only GPIO: the host must drive DATA low to start a read.
  • 3: NC No connection Leave disconnected Bare four-pin package only; not a ground pin.
  • 4: GND Ground ESP32 GND Three-pin breakouts can reorder +, DATA/OUT/S and −. Follow printed labels, not this bare-package order.

04Wiring Diagram

Bare sensor: vented front facing you, leads down, pins 1–4 run VCC, DATA, NC, GND from left to right for the standard package. A three-pin breakout is a different assembly: follow its VCC/+/DATA/OUT/S/GND/− labels.

Use 3.3 V supply and a DATA pull-up to 3.3 V. Check module documentation or unpowered resistance between DATA and VCC before adding a duplicate pull-up. Never assume an onboard resistor goes to a safe voltage. Keep leads short and unplug USB before changing wiring.

Wiring and matching Arduino code

DHT22 on GPIO4

Use the 3.3 V wiring above. This example uses DHT22, not DHT11.

esp32_dht22_readings.ino 
#include <DHT.h>

constexpr uint8_t DHT_PIN = 4;
DHT dht(DHT_PIN, DHT22);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  delay(2500);
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();
  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("DHT22 read failed: check wiring, pull-up and sensor type.");
    return;
  }
  Serial.print("Temperature: ");
  Serial.print(temperature, 1);
  Serial.print(" C | Humidity: ");
  Serial.print(humidity, 1);
  Serial.println(" % RH");
}

The temperature call uses the same cached measurement as the humidity call. Do not force faster reads. This blocking delay is adequate for this isolated demonstration; a larger project can schedule reads with millis().

OKExpected Output

Illustrative output, not a measured result: Temperature: 23.4 C | Humidity: 48.2 % RH. Your room determines the values; they need not change on every line. NaN means an invalid read, not 0 °C. Keep the sensor away from condensation and let it settle after moving it.

DHT22 versus DHT11 and reading limits

The sensor exchanges timed pulses on DATA; this is not I2C and not the Dallas OneWire protocol. The library checks the response and returns temperature and humidity. A failed checksum or timeout produces NaN.

Adafruit describes older DHT11 parts as 0–50 °C and 20–80% RH with coarser accuracy, versus a wider range for its DHT22. DHT11 revisions and modules differ, so consult the actual datasheet. Our historical /guides/read-temperature-dht22.html quick build now deliberately uses DHT11 and a DHT11 video; it is labeled that way in the links below.

The library limits both sensor types to one new cached measurement per 2 seconds. Updating the screen faster does not make the sensor sample faster. Avoid breathing directly on it when comparing readings; nearby heat and moisture affect local air conditions.

06Troubleshooting

ProblemPossible causeSolution
Read failed / NaN Incorrect wiring, missing pull-up, wrong DHT type or damaged sensor. Unplug USB, verify package orientation and DATA GPIO4, check 3.3 V supply/shared GND and the 10 kΩ pull-up. Use DHT22 in the constructor and short leads.
DHT.h: No such file Adafruit DHT library is absent or installed into a different IDE environment. Install DHT sensor library by Adafruit in Library Manager and accept Adafruit Unified Sensor. Reopen the sketch and compile again.
Values repeat Read caching or slowly changing room conditions. Keep at least 2 seconds between samples. Repeated values are normal; do not force reads faster to seek variation.
Temperature too warm / humidity unexpected Nearby regulator heat, enclosure airflow, condensation or an uncalibrated part. Move the sensor away from heat, allow settling time and compare in the same air conditions. Do not infer precision from one decimal place.
Bare package order differs from module Breakout manufacturer rearranged the header. Follow your module labels and schematic. Do not transfer the bare four-pin left-to-right sequence to a three-pin board.
